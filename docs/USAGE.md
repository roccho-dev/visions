# visions — Windowsプレビュー

ZIPを展開し、`Visions.exe`を開きます。.NETの事前導入・管理者権限は不要な構成です。署名は未実施のため、SmartScreenや社内の実行制限で止まることがあります。組織の制限を回避せず、IT担当へ確認してください。

## 1. 動きを確認する

「デモ」→「可視化を開く」。ブラウザには合成データによる流れ・経過・根拠が表示されます。実測値ではありません。

### Process Lens（合成・外部World）

Windowsアプリの「Process Lens」を開き、「合成デモ」を押すと、経営→管理、管理→現場という**架空の**Lensを表示します。視点ボタンで切り替え、同じ再帰プロセスを左右比較できます。ノード・辺を選択するとSVG上に元ref・提供された状態・根拠参照を表示します。「戻る」で以前の視点へ復帰します。外部World JSONもブラウザでローカルに読み込めますが、入力の出所や業務内容の真偽までは検証しません。下部詳細画面はありません。

Windows観測ログは業務のPlan/Relationを含みません。現在のfocusログを自動対応付けせず、契約が未提供なら業務上のズレは不明です。画面の左右に表示される名前は固定の役職定義ではありません。

## 2. 対象アプリを観測する

対象を選ぶ→観測許可にチェック→「記録開始」→普段の操作→「停止」→ブラウザで「再読込」。15分で自動停止します。記録開始・停止はWindowsアプリだけにあり、Viewerは読取専用です。

初期版が捉えるのはUIAのフォーカス変化だけです。クリック・入力内容・画面録画・全業務の完全な履歴ではありません。画面名・患者名・入力文字は読みません。OSの数値IDは記録区間ごとの仮名に変換します。仮名は別区間との人物・要素照合には使えません。別プロセス、管理者権限の対象、UIA非対応、仮想画面の動作は保証しません。

処理が応答しないときは、停止操作でvisions自身の取得子プロセスだけを終了します。対象業務アプリは終了・操作しません。終了Recordがない区間は未完了として表示します。取得できなかったこと自体を検出できない場合もあるため、常に観測範囲は限定的です。

## 3. 既存出力を取り込む

「出力ファイルを取り込む」で、使用を許可されたCSV等を選びます。32 MiBまでをバイト単位でコピーし、SHA-256を記録します。元ファイルの変更、業務DBへの接続、GUIでのエクスポート操作はしません。

**コピー本体の個人情報は除去しません。** 本体は端末のartifactsに別保存し、Viewerには本体・元ファイル名・元パスを配信しません。ハッシュ一致はコピーの同一性であり、業務データの全件抽出や移行完了の証明ではありません。

## 保存と終了

`%LOCALAPPDATA%\visions\captures`にRecord v1のJSONL、`artifacts`に取り込んだ本体を保存します。「保存場所を開く」で確認できます。自動削除・暗号化・企業向けアクセス管理は未実装です。権限のある試験端末で試し、アプリを閉じて不要な記録と本体を削除してください。患者データを使う本番運用にはまだ使用しないでください。

ブラウザは`127.0.0.1`限定のランダムなURLに接続します。URLは第三者に渡さないでください。外部送信・外部CDN・自動更新はありません。ただし同一ユーザー権限の別プロセスから完全に隔離する仕組みではありません。

可視化は先頭200ステップ、記録選択は新しい100区間を表示します。1区間は5000レコード未満・4 MiB未満を上限とします。時間は経過時間、反復は反復として表示し、業務名・効率・完了を推定しません。
